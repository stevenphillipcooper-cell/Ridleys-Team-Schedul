Connect your shared schedule

This scheduler stores its data in a free Supabase database so your whole team sees and edits the same live schedule. You only do this once — then share the same link (and these two values) with anyone who needs access.

Enter your Supabase details

      
    


    

      First time? Set up the free database (5 minutes) ▸
      
    
        
  1. Go to supabase.com and create a free account, then click New project. Give it any name and password; wait ~2 min for it to provision.
    2. 
        
  2. In the left sidebar open SQL Editor → New query, paste the block below, and click Run. This creates the shared table and allows access with the anon key:
          
    create table if not exists scheduler_kv (
  key text primary key,
  value jsonb,
  updated_at timestamptz default now()
);
alter table scheduler_kv enable row level security;
create policy "anon read"  on scheduler_kv for select using (true);
create policy "anon write" on scheduler_kv for insert with check (true);
create policy "anon update" on scheduler_kv for update using (true);
create policy "anon delete" on scheduler_kv for delete using (true);
    
        
    3. 
        
  3. Open Project Settings (gear icon) → API. Copy the Project URL and the anon / public key into the fields above.
    4. 
        
  4. Click Connect. Share this same file/link plus those two values with your team — everyone who enters them sees the same live schedule.
    5. 
      

      
Note: the anon key is safe to share with your team — it only allows access to this one table. Anyone with it can view and edit the schedule, which is the point. Don't post it publicly.
